# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：批量合并、风险排序、差异失效分区和规则变更待复核
- 历史基线：版本、批准人、原因、关联运行、规则版本和启用状态
- 忽略规则：动态区域选择器、作用范围、最大色差、规则版本和启用控制
- 结果导出：导出包含运行、差异和审批证据（含依据版本）的 CSV

## 版本对账

- 打开评审时会创建评审会话，记下当前有效基线版本与规则集版本；提交审批做乐观锁校验。
- 忽略规则新增、修改、删除都会提升规则集版本：
  - 作用域内的待审批运行先失效（`stale`），差异区域立即按新规则重算，评审人重新确认后才可审批；
  - 已批准运行与有效基线的原判定保留原样，仅挂“待复核”标记，确认无需改判后解除。
- 同一运行在多个标签页同时提交时，只有最早通过版本校验的审批能创建基线；冲突返回 409（`RUN_DECIDED` / `RULES_CHANGED` / `BASELINE_CHANGED`），表单输入保留，可按最新版本重试。

## 测试

```bash
npm test
```

包含对账纯逻辑单测、Mock API 集成测试，以及模拟两个标签页（独立 JS 上下文、共享 localStorage）随机交错并发的审批裁决测试。

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键；旧数据会自动迁移补齐版本字段。
