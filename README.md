# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：批量合并、风险排序、失效重评、规则改动待复核和审批入口
- 历史基线：版本、批准人、原因、关联运行、规则版本、待复核状态和启用状态
- 忽略规则：动态区域选择器、作用范围、最大色差、规则集版本和启用控制
- 结果导出：导出包含运行、差异、规则版本和审批证据的 CSV

## 版本对账

- 打开评审时锁定快照：当前有效基线（ID + 版本）与规则集版本，提交时随审批一起对账。
- 规则新建、启停、删除都会递增规则集版本：待审批运行的旧判定立即失效并按新规则重算差异区域；已批准运行与有效基线保留原样，自动列入待复核（可在运行或基线页确认，确认只标记、不改版本）。
- 两个标签页同时提交同一批截图时，服务端做乐观并发校验：运行已被判定返回 `run-decided`，规则版本漂移返回 `rules-changed`，基线已被顶替返回 `baseline-changed`（HTTP 409）。只有最早到达的有效审批会停用旧基线并创建新版本；后到的审批保留全部表单输入，对齐最新版本后可一键重试。

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键。
